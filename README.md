# API для управления списком задач.
Реализован на FastAPI с использованием in-memory хранилища.

## Цель и задача
Создать минималистичный сервис для управления задачами, демонстрирующий чистую архитектуру, разграничение ответственности и тестирование.

## Начало работы
### 1. Запуск сервиса через Docker
``` bash
docker compose build
```
``` bash
docker compose up
```


## Структура
```
├── app/
│   ├── api/
│   ├── schemas/
│   ├── services/
│   ├── tests/
│   ├── models/
│   ├── db.py
│   └── main.py
├── .gitignore
├── docker-compose.yml
├── Dockerfile
├── pytest.ini
├── README.md
└── requirements.txt
```
#### Каталоги, содержащиеся в проекте:
- `app` - Основная логика приложения
- `api` - API эндпоинты
- `models` - Модели Pydantic
- `query_objects` - Объекты запросов в базу данных
- `schemas` - Схемы ответов API
- `services` - Бизнес логика вынесенная в сервисы
- `tests` - Тесты
#### Файлы, содержащиеся в проекте:
- `main.py` - инициализация FastApi + подключение всех эндпоинтов
- `database.py` - In-memory база данных + Dependency для получения in-memory хранилища задач

## Функционал
Сервис предоставляет следующие эндпоинты:
- POST /tasks - создание новой задачи
- GET /tasks/{id} — получение задачи по ID
- GET /tasks — получение списка всех задач

## Тестирование
Запуск тестов
```
pytest .
```
